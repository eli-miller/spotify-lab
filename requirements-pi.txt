# Minimal deps for unattended cron scripts on the Pi:
# shazam_cluster/create_playlists.py, shazam_cluster/fetch_tracks.py,
# release_radar/run.py, release_radar/new_releases.py
#
# Does NOT include pandas/matplotlib/seaborn/pyqt/ipython — those are only
# needed for interactive dev work (cluster.py, inspect_dataset.py, sandbox.py),
# which isn't run headless. See environment.yml for the full Mac dev environment.
#
# scikit-learn is pinned to match the Mac environment that trains the
# clustering model — joblib.load() doesn't guarantee cross-version
# compatibility when unpickling a KMeans/StandardScaler.
#
# The piwheels scikit-learn/numpy build for Raspberry Pi OS links against
# libopenblas.so.0 as a system library rather than bundling it — without it,
# `import sklearn` fails with "ImportError: libopenblas.so.0: cannot open
# shared object file". Install it first:
#   sudo apt-get install -y libopenblas0
